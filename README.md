# 时痕 · TIME ECHO

一款时间回溯 + 幽灵克隆体合作解谜的网页游戏。每一次尝试都会被记录成一条时间线，按 `R` 凝固成幽灵克隆体，在下一轮循环中原样重演你的操作——与过去的自己合作，踩住开关、顶住大门、规划每一条时间线的任务。

**在线试玩**：`https://<你的用户名>.github.io/time-clone/`（推送并开启 GitHub Pages 后可用）

## 特性

- 8 个手工设计关卡，难度递进：热身 → 幽灵开关 → 双重保险 → 拉杆接力 → 哨兵走廊 → 潮汐闸门 → 期末小考（全元素综合）→ 终极时间线
- 确定性时间回溯：幽灵克隆体按 tick 精确重演录制输入
- 机关元素：压力板 / 一次性拉杆 / 条件门 / 定时闸门 / 单向地砖 / 尖刺 / 折返巡逻哨兵
- 纯单文件 HTML + Canvas，零依赖、零素材（WebAudio 合成音效），全部源码不到 1000 行
- 连续浮点移动，操作丝滑

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| R | 凝固本条时间线为幽灵克隆体 |
| Z | 撤销上一次凝固 |
| X | 清除全部克隆体 |
| M | 静音 |

## 本地运行

直接双击打开 `index.html` 即可游玩；或启动本地服务器：

```
python -m http.server 8899
# 浏览器访问 http://localhost:8899
```

## 文件

- `index.html` — 游戏本体（单文件，含全部逻辑与关卡数据）
- `素材图鉴.html` — 全部游戏元素的可视化参考图鉴（换素材用）
- 关卡采用 Sokoban 风格的 ASCII 地图格式：地图即文本，一格一字符（`#` 墙 `.` 地板 `^` 尖刺 `S` 出生 `E` 出口 `P` 压力板/拉杆 `D` 条件门 `G` 定时闸门 `>` 单向地砖），参数按阅读顺序与符号一一配对，加关只需画一张字符地图
